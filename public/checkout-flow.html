Exploring options

How verification talks to the gate

Option A

Sheet-as-database

  • Every signup writes a row to Google Sheets automatically
  • You mark "Paid" in the sheet after checking Venmo
  • Site polls the sheet — status badge flips live for the user
  • Gate staff use the same sheet, filtered to "Paid," as the check-in list
Option B

Admin dashboard, sheet export

  • You confirm payments in a simple built-in admin screen
  • Sheet updates automatically in the background — not your workflow
  • Gate check-in happens on a phone via search-by-name in the dashboard
  • Cleaner UI for you, sheet stays purely for accounting/reuse
Option C

QR wristband handoff

  • Builds on A or B — once confirmed, guest gets a QR code
  • Gate volunteer scans QR on a phone, marks "checked in"
  • Fastest at the door once you're past ~50 guests
  • More setup work now, pays off at scale
